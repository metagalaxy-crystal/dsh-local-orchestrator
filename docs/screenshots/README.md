|---|---|---|
| `01-overview.png` | 总览页 | 显存三段条（已用 / 可调度 / 保留）+ 资产卡片网格 |
| `02-assets.png` | 资产页 | 顶部「运行框架」条、主模型卡片、配套组件 chips、⚠ 缺文件标记 |

- `04-usage.png` 右上角原本有本机 `C:\Users\<用户名>\.dsh\...` 路径，已抹掉再入库；
